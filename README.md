# 815 农业推广学 · 考研学习站

面向江西农业大学 27 考研考生的 **815 农业推广学** 静态学习网站。零依赖构建，纯 HTML/CSS/JS，可直接托管在 GitHub Pages 等任意静态空间。

## 功能

- **章节学习**：18 章考点卡片（考频星级、助记、对比速记表、真题回顾）
- **名词解释**：76 个名词翻卡背诵，支持章节/已背状态筛选与关键词搜索
- **历年真题**：2010–2026 回忆版真题，按年份/题型筛选，自动关联考点
- **自测练习**：选择/判断/填空/简答四种题型，即做即判带解析，可按章节筛选
- **学习进度**：章节完成度、名词已背标记、答题记录全部保存在浏览器本地（localStorage）
- **双端适配**：桌面侧边栏 + 移动端底部导航；图表离线时自动降级为静态条形图

## 如何扩充题库 / 知识点

所有数据都是自包含的 JS 文件（向 `window.DATA` 注入），无需构建工具：

- **加题目**：在 `data/quiz.js` 对应题型数组里追加对象即可，格式见各文件头部注释。
  答题记录按「章节 + 题干哈希」生成稳定 ID 存储在本地，**插入、删除、调整题目顺序都不会打乱用户已有进度**。
- **加名词**：在 `data/terms.js` 追加 `{n:名词, ch:章号, s:考频1-3, d:释义, k:关键词}`。
- **加章节**：在 `data/chapters.js` 追加章节对象；全站章节数、进度条、导航均为动态统计，无需改代码。
- **加真题**：在 `data/exams.js` 追加 `{y:年份, type:题型, q:题干, ans:答案要点, k:[考点关键词]}`，
  首页「高频考点」榜与考点关联会自动更新。

修改后本地验证：在项目根目录起一个静态服务器（如 `python -m http.server 8000`），浏览器打开 `http://localhost:8000` 检查即可；推送到 GitHub 后 Pages 自动更新。

## 安装为应用（PWA）与多设备同步

- **安装**：本站作为「考研学习站」应用的一部分提供。打开导航主页 https://karrystar.github.io/ ，用 Chrome / Edge（安卓/电脑）菜单选择"安装应用"或"添加到主屏幕"，即可获得一个独立应用，应用内可进入 815 与 341 两个学习站，并支持**离线使用**（离线缓存由根站 Service Worker 统一覆盖）。
- **多设备同步**：页面顶栏的 ↻ 按钮打开同步设置，支持两种云端：
  - **WebDAV**：坚果云（推荐，注册后在"安全选项"里生成应用密码）、群晖、Nextcloud 等；
  - **OneDrive**：微软个人账号。首次使用需在 Azure 门户注册一个 SPA 应用（免费），把两个学习站的重定向 URI 填入，将「客户端 ID」粘贴进设置即可登录。
- **同步方式**：按题目/名词/章节为粒度记录修改时间，多端修改自动合并（后写者胜出，删除会被同步）；云端按站分文件备份，**同步配置在 815 / 341 之间互通**，任一站配置一次即可。
- 数据与凭据均为**明文**存储（本机 localStorage 与云端 JSON），未做加密，请勿在共用设备上保存密码。
